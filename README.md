# tauri-qwen-perfect 配布物

社内の文書・画像を **一切外部に送らず**、手元のPCだけで要約・校正・匿名化・文字起こしを
行うローカルAIアシスタント（macOS / Apple Silicon 版）。

> 📘 **はじめての方へ：図解つきの操作ガイドがあります。**
> https://tk20260401.github.io/tauri-qwen-local-assistant-release/
> インストール・初回起動・使い方を、画面イメージ付きで順を追って説明しています。

## 動作環境（推奨スペック）

このアプリ自体は軽量ですが、AIの処理は手元のPCで動くため、
実用的な速度にはある程度のスペックが要ります。

- **対応機種**：Apple Silicon（M1以降）搭載の Mac。※この版は Intel Mac では動きません
- **OS**：macOS 13（Ventura）以降を推奨
- **メモリ**：16GB以上を推奨（最低8GB）
- **空きディスク**：15GB以上（AIモデルの保存用）
- **Ollama**：必須（別途インストール）

### メモリが少ないMac（8GBなど）の場合

標準の `qwen3.5:9b` は重いため、より小さいモデルに切り替えてください。

1. ターミナルで軽量モデルを取得：`ollama pull qwen2.5:3b`
2. アプリ上部の「モデル」ドロップダウンで、取得したモデルを選ぶ

小さいモデルは速く動く代わりに、回答の精度は下がります。用途に合わせて選んでください。

> 性能はお使いのMacのスペックに依存します。低スペック環境での動作は保証できません。

## 2. インストールと初回起動

このアプリは Apple の開発者署名を付けていません。初回だけ macOS の警告を手動で
解除する必要があります（一度許可すれば次回から普通に開けます）。

1. `.dmg` をダブルクリックし、アプリを「アプリケーション」へドラッグする。
2. アプリを起動すると「開発元を確認できません」と出る → 「完了」で閉じる。
3. アップルメニュー →「システム設定」→「プライバシーとセキュリティ」を開く。
4. 下の方の「"tauri-qwen-perfect" は…ブロックされました」の横の
   **「このまま開く」** をクリックし、パスワード（またはTouch ID）で承認する。
5. 確認ダイアログでもう一度 **「開く」**。以降は普通に起動できる。

### 「壊れているため開けません」と出た場合（方法B）

上の手順で「このまま開く」が出ず、代わりに「壊れているため開けません」と表示される
ことがあります。**アプリは壊れていません。** ダウンロードに付く「隔離」の印が原因です。
アプリを「アプリケーション」に入れた状態で、ターミナル（アプリケーション → ユーティリティ →
ターミナル）を開き、次の1行を貼り付けて実行してください。

```
xattr -dr com.apple.quarantine "/Applications/tauri-qwen-perfect.app"
```

このコマンドは印を外すだけで、アプリの中身は変更しません。実行後、普通にダブルクリック
すれば開きます。必要なのは初回の1回だけです。

> 警告は「署名がない」ことに対するもので、危険を検知したという意味ではありません。
> このアプリは通信を端末内（localhost）に限り、読み込んだ文書・画像を外部へ送りません。

## 3. AI本体（Ollama）の準備

このアプリは AI を内蔵していません。別途 Ollama を入れ、モデルを取得してください。

1. https://ollama.com からインストール。
2. ターミナルで必要なモデルを取得（初回のみ・サイズ大）。

   ```
   ollama pull qwen3.5:9b     # 要約・校正など（本体）
   ollama pull bge-m3         # 社内資料の検索（記憶機能）を使う場合
   ollama pull qwen2.5vl      # 画像の文字読み取りを使う場合
   ```

3. Ollama が起動していれば、アプリが自動で見つけて動きます。
