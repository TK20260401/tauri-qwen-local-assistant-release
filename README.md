# tauri-qwen-perfect 配布物

社内の文書・画像を **一切外部に送らず**、手元のPCだけで要約・校正・匿名化・文字起こしを
行うローカルAIアシスタント（macOS / Apple Silicon 版）。

## 1. ダウンロード

アプリ本体（.dmg）は GitHub Releases から取得してください。

- 最新版：https://github.com/TK20260401/tauri-qwen-local-assistant-release/releases/latest
- 直接リンク（v0.1.0）：
  https://github.com/TK20260401/tauri-qwen-local-assistant-release/releases/download/v0.1.0/tauri-qwen-perfect_0.1.0_aarch64.dmg

> このフォルダにはマニュアルのみを置いています。アプリ本体は容量が大きいため
> リポジトリには含めず、Releases に置いています。

## 2. インストールと初回起動

このアプリは Apple の開発者署名を付けていません。初回だけ macOS の警告を手動で
解除する必要があります（一度許可すれば次回から普通に開けます）。

1. `.dmg` をダブルクリックし、アプリを「アプリケーション」へドラッグする。
2. アプリを起動すると「開発元を確認できません」と出る → 「完了」で閉じる。
3. アップルメニュー →「システム設定」→「プライバシーとセキュリティ」を開く。
4. 下の方の「"tauri-qwen-perfect" は…ブロックされました」の横の
   **「このまま開く」** をクリックし、パスワード（またはTouch ID）で承認する。
5. 確認ダイアログでもう一度 **「開く」**。以降は普通に起動できる。

> 警告は「署名がない」ことに対するもので、危険を検知したという意味ではありません。
> このアプリは通信を端末内（localhost）に限り、読み込んだ文書・画像を外部へ送りません。

## 3. AI本体（Ollama）の準備

このアプリは AI を内蔵していません。別途 Ollama を入れ、モデルを取得してください。

1. https://ollama.com からインストール。
2. ターミナルで必要なモデルを取得（初回のみ・サイズ大）。

   ```
   ollama pull qwen3.5:9b     # 要約・校正など（本体）
   ollama pull bge-m3         # 社内資料の検索（記憶機能）を使う場合
   ollama pull qwen2.5vl      # 画像の文字読み取りを使う場合
   ```

3. Ollama が起動していれば、アプリが自動で見つけて動きます。
