1動作環境（お使いのMacの確認）

アプリ本体は軽いですが、AIの処理は手元のPCで動くため、ある程度のスペックが要ります。

⚠️ 最初に確認してください
この版は Apple Silicon（M1以降）専用です。Intel製のMacでは動きません。
確認方法：画面左上の🍎 →「このMacについて」→「チップ」が Apple M1／M2／M3／M4 なら対象です。

ℹ️ 性能について

2インストール（3ステップ）

  1. ダウンロード配布ページから tauri-qwen-perfect_0.1.0_aarch64.dmg をダウンロードします。
  2. 開くダウンロードした .dmg ファイルをダブルクリックします。
  3. アプリを移動開いた画面で、アプリのアイコンを「アプリケーション」フォルダへドラッグします。

3初回起動 ―「壊れている」と出たら

✅ まず安心してください
「壊れているため開けません」と出ても、アプリは壊れていません。
これは、Appleの有料登録をしていない個人開発アプリを、ネット経由でダウンロードしたときにmacOSが出す安全のための表示です。初回の1回だけ、次の操作で開けるようになります。

方法A：まずこちらを試す（マウス操作だけ）

  1. アプリを一度開こうとするアプリケーションの中の tauri-qwen-perfect をダブルクリック。警告が出たら「完了」で閉じます（「ゴミ箱に入れる」は押さない）。
  2. 設定を開く🍎 →「システム設定」→「プライバシーとセキュリティ」を開きます。
  3. 「このまま開く」を押す下の方に出る「"tauri-qwen-perfect"は…ブロックされました」の横の 「このまま開く」 をクリックし、パスワードまたはTouch IDで承認します。
🔧 方法B：方法Aで「このまま開く」が出ないとき（確実な方法）
アプリを「アプリケーション」に入れた状態で、ターミナル（アプリケーション → ユーティリティ → ターミナル）を開き、下の1行をそのままコピーして貼り付け、return を押します。
xattr -dr com.apple.quarantine "/Applications/tauri-qwen-perfect.app"
このコマンドは、ダウンロードに付いた「安全のための印」を外すだけで、中身は一切変更しません。実行後、アプリを普通にダブルクリックすれば開きます。
ℹ️ 2回目以降は
一度開けば、次からは普通にダブルクリックするだけで起動します。この操作が必要なのは最初の1回だけです。

4AIの準備（Ollama）

このアプリはAI本体を内蔵していません。無料の Ollama を入れて、モデルを取得します。

  1. Ollamaを入れるhttps://ollama.com からダウンロードしてインストールします。
  2. モデルを取得するターミナルで下を実行します（初回のみ・サイズが大きいのでWi-Fi推奨）。
    ollama pull qwen3.5:9b # 要約・校正など（本体） ollama pull bge-m3 # 社内資料の検索を使う場合 ollama pull qwen2.5vl # 画像の文字読み取りを使う場合
  3. 準備完了Ollamaが起動していれば、アプリが自動で見つけて動きます。

5使い方（基本の流れ）

① 文をコピー
／ファイル選択 → ② 指示を入力
／テンプレを押す → ③ 解析ボタン
を押す
tauri-qwen-perfect（画面イメージ）
📝 ビジネス校正 🛡️ マスク・匿名化 🔍 原因特定・分析 📄 箇条書き要約 📎 ファイル選択 📋 クリップボードを解析
  • 入力の渡し方：文章をコピー（⌘+C）／「📎 ファイル選択」／ウィンドウにドラッグ&ドロップ。
  • 対応ファイル：pdf・docx・xlsx・txt・csv・md・画像（png/jpg/jpeg/webp）。
  • テンプレート：4つのボタンを押すと、指示が自動で入ります。そのまま実行できます。
  • 実行：青い「📋 クリップボードを解析」ボタン。⌘+return でもOK。
  • 画像の文字起こし：画像を選ぶと中の文字を読み取り、そのまま要約や校正にかけられます。
  • 保存：回答の下のボタンで md／txt／csv／docx／pdf／xlsx に保存できます。
🧠 社内資料の検索（記憶機能）
「🧠 フォルダを記憶」で資料フォルダを読み込ませ、「記憶を参照」にチェックを入れて質問すると、関連箇所を自動で探して回答に使います。すべて手元で完結します（初回は ollama pull bge-m3 が必要）。

6動作が重いとき（メモリの少ないMac）

標準の qwen3.5:9b が重い場合は、より小さいモデルに切り替えます。

  1. 軽いモデルを取得
    ollama pull qwen2.5:3b
  2. 切り替えるアプリ上部の「モデル」ドロップダウンで、取得したモデルを選びます。
🔁 速さと精度のバランス
小さいモデルは速く動く代わりに、回答の精度は下がります。用途に合わせて選んでください。
